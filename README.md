# Leigh Syndrome: Interactive Learning Game

An educational video game created for an AP Biology presentation about Leigh Syndrome. This interactive experience teaches students about mitochondrial function, ATP production, and how genetic mutations cause this rare metabolic disorder.

## About Leigh Syndrome

Leigh Syndrome is a rare inherited neurometabolic disorder that affects the central nervous system. It's caused by mutations in mitochondrial DNA or nuclear DNA that affect mitochondrial function, leading to progressive loss of mental and movement abilities due to insufficient ATP production.

## Features

This game includes three interactive mini-games, each with tutorials:

### 🎮 Game 1: Mitochondria Defense
- **Gameplay**: Click to collect nutrients (glucose, oxygen) while avoiding toxins (cyanide) and mutations
- **Objective**: Maintain ATP levels for 60 seconds
- **Learning**: Demonstrates how mitochondria require specific nutrients for ATP production and how toxins/mutations disrupt this process

### ⚡ Game 2: Energy Meter Challenge
- **Gameplay**: Complete everyday tasks that consume ATP while managing energy levels
- **Objective**: Complete as many tasks as possible before ATP depletion
- **Learning**: Shows how mitochondrial dysfunction causes rapid energy depletion, making simple activities exhausting
- **Special Feature**: Mutation occurs in round 4, drastically reducing ATP regeneration

### 🧬 Game 3: Pathway Puzzle - Electron Transport Chain
- **Gameplay**: Drag and drop molecules to the correct complexes in the ETC
- **Objective**: Correctly place all 5 molecules (NADH, FADH₂, Electron, O₂, H⁺)
- **Learning**: Teaches the exact biochemical pathway of ATP production and how Complex IV mutations (common in Leigh Syndrome) block the entire process

## How to Use

1. **Open the game**: Simply open `index.html` in any modern web browser
2. **No installation required**: The game runs entirely in the browser using HTML5, CSS3, and JavaScript
3. **Navigate**: Use the main menu to select games or read about Leigh Syndrome
4. **Tutorials**: Each game has a built-in tutorial explaining the rules and biology

## Educational Objectives

Students will learn:
- How mitochondria produce ATP through cellular respiration
- The role of the electron transport chain in energy production
- How genetic mutations disrupt mitochondrial function
- Why Leigh Syndrome causes severe neurological symptoms
- The relationship between energy demands and cellular ATP production
